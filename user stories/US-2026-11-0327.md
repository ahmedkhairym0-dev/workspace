Extend Consultation Contract and Consultation Invoice so users can maintain consultation tables through Excel, bill actual consultant numbers within available monetary balances, and allocate overtime for the same consultants across multiple recipients.


Consultation billing accepts actual consultant numbers based on each item’s remaining balance and the contract’s remaining monetary allowance. Standard table transfer alone does not provide the requested configurable construction Excel-template workflow.


Required Behavior


    Extend the existing 
    Construction Export Template workflow to these four tables:


Parent	Table	Child DocType
Consultation Contract	Details (items)	Consultation Contract Detail
Consultation Contract	Rate Increases	Consultation Contract Rate Increase
Consultation Invoice	Regular Details (invoice_details)	Consultation Invoice Detail
Consultation Invoice	Overtime Details (overtime_details)	Overtime Details


    Add Download and Upload buttons to all four child tables using the existing Construction Contract Excel workflow. Include template column selection, one default per parent/child pair, default preselection, populated and blank 
    .xlsx downloads, and headers containing field labels and identifiers. Support the reference upload formats .xlsx, .xlsm, and .xlsb, reading the first worksheet.
    Uploads must update identified rows without duplicating them or replacing unrelated rows. Support new editable contract-detail, rate-increase, and overtime rows. Regular invoice rows must retain their contract and rate-period references; uploads must not introduce unrelated job titles or arbitrary billing rows.
    Import editable business inputs and recalculate derived values. Preserve generated contract rate-period rows, scheduled increases, exclusions, and read-only calculations. Identify invalid spreadsheet rows and fields before applying changes.
    Allow 
    contract Number to be zero with a positive Rate. Add Over Billing Allowance (%), Used Over Billing Allowance Amount, and Remaining Over Billing Allowance Amount to Consultation Contract. Copy the percentage from Construction Settings for a new contract, allow draft edits, and preserve an explicit zero. The two amount fields are read-only and calculated from submitted regular invoices.
    Bill using actual invoice Number (consultants_qty), including values equal to or greater than the contracted Number. Do not apply a separate percentage quantity cap or check_overbilling_allowance_on_every_item. Accept quantities when the calculated regular amount fits the item’s remaining balance plus the remaining shared monetary allowance. Zero-Number contract rows can draw from the shared monetary allowance.
    The shared monetary allowance equals sum(items.total_amount) multiplied by the contract percentage / 100. Used allowance equals sum(max(submitted regular amount for each item - item.total_amount, 0)). Remaining allowance equals max(total allowance - used allowance, 0). Tax and overtime amounts do not consume this pool.
    Spend each item's remaining amount first. Any additional regular billing must fit the remaining shared allowance; unused base balances on other items cannot hide that excess. Reject excess draws without changing invoice inputs. Check the latest submitted amounts under a contract lock before submission, and update both displayed allowance amounts on submission and cancellation. Existing historical excess may remain visible, but cannot authorize further allowance draws.
    Keep invoice creation, row mapping, and Reload Contract Rows available for depleted rows. Enforce the monetary allowance on recalculation, Excel preview, saving, and submission. Contract dates and applicable rate periods still determine the available billing rows.
    Allow the same job title and consultants on separate overtime rows against different construction contracts or 
    Allocated to Developer Company. Do not cap the combined consultant count across allocations by invoice headcount. Retain row-specific hours, rates, amounts, and allocation destinations.
    Preserve source-contract membership, valid billing periods, positive billable inputs, construction-contract eligibility, tax calculations, and existing submission/cancellation effects. Contract invoiced and remaining amounts must continue reflecting submitted invoices, including negative remaining amounts after overbilling.


Test Setup


Use illustrative staging data. Create a fresh consultation contract for each independent scenario unless reuse is explicitly stated.


    Open the 
    Consultation Contract list and create a new document. Select a company, consultant supplier, project, and two submitted construction contracts belonging to that company and project. Complete the usual account and currency fields; use the company currency, conversion rate 1, and no taxes for the numeric checks below.
    Set 
    Contract Starting Date to 2027-01-01 and Contract Duration in Months to 2. In Details, retain two job titles: A with Number = 1, and B with Number = 0. Set Rate = 2400 for both. Remove other unused detail rows and leave Rate Increases empty. Save the draft.
    For the numeric A/B invoice checks below, set the contract's Over Billing Allowance = 400%. There is no separate Number limit. Total monetary allowance is 19200. The first submitted regular invoice consumes 7200, leaving 12000; the second identical invoice consumes the remaining 12000.
    Verify a Number above the former percentage quantity cap is accepted when its calculated amount fits available monetary capacity. Verify a further increase is rejected when it exceeds that capacity. Repeat with both values of Check Overbilling Allowance on Every Item; the result must be unchanged.
    For monetary boundaries, use a row with base total 1000, submitted billing 900, and 20% allowance. A new regular amount of 300 uses the remaining base 100 and allowance 200. Reject 300.01. Cancel the invoice and verify allowance usage is restored. Verify that unused base balances on another item do not offset excess, and overtime/taxes do not consume allowance.
    When a criterion requires an invoice, submit its contract and select 
    Create → Consultation Invoice. Use the generated billing period and set Extra Days = 0. Enter regular-detail Number = 3 for A and 2 for B. Leave overtime empty unless the criterion supplies overtime rows.
    For Excel checks, configure templates containing row identity, the relevant editable inputs, and enough reference information to preserve contract/rate-period relationships. Use 
    Construction Export Template → new document → select Parent DocType and the target table → save → Set Template → select columns → Export. Mark one configured template per parent/child pair as Is Default and save.
